# ML System Design — Recommendation System

This project is a hands-on implementation of an end-to-end machine learning system for recommendation and ranking.

## Goals

Build a production-style ML system that includes:

- data pipelines
- feature engineering
- model training
- ranking
- serving
- monitoring
- experimentation

## Project Theme

E-commerce recommendation / ranking system.

Predictions:

- click probability
- purchase probability
- ranking score

## Dataset Candidates

- RetailRocket
- Instacart
- Amazon Reviews
- MovieLens
